# App Festival - Documento de Contexto
Este é um site de um festival de músicas. Crie todo o projeto dentro desta pasta ´festival´.

##Tecnologias
Use estritamente as tecnoligas citadas abaixo:
- HTML
- CSS


Não use nem instale nada neste projeto.

Este projeto **NÃO USA** javascript.

## Refêrencias
- explore a minha pasta ´referencias´
- Entenda como eu programo
- Entenda as tags que eu conheço
- Você deve fazer parecido para que eu possa compreender seu código
- Você pode usar tags e estilos novos **se necessario**, mas faça de forma contida

## Páginas
- index.html - Página inicial
- turismo.html - Página que exibe as opções de lazer e turismo na cidade do festival

### Regras
- Crie um arquivo CSS geral do site compartilhado entre as páginas
- Crie um arquivo CSS individual para cda pagina que contem sua estilização especifica

    - Os arquivos individuais devem ter o mesmo nome da página de HTML que ele está atrelado
